# Book Recommendation System

## Overview

This project explores machine learning techniques for recommending books based on popularity, content similarity, and user preferences. Using a dataset of approximately 200,000 books, the system combines different recommendation approaches to help users discover relevant books.

## Project Report
https://github.com/KCoder29/book-recommendation-system/blob/main/Book_Recommendation_System_Project_Report.pdf

## Approaches

- **Popularity-Based Filtering:** Recommends books based on overall popularity.
- **Content-Based Filtering:** Suggests books based on content-related similarities.
- **Collaborative Filtering:** Uses user preference patterns to identify relevant recommendations.
